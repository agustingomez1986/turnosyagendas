# Backlog del producto

## Suscripciones

- Permitir que un plan de suscripción incluya varios servicios.
- Permitir distintas cantidades de clases para cada servicio dentro del mismo plan.
- Renovación automática de suscripciones.
- Suspensión temporal de suscripciones.
- Planes familiares.

## Agenda

- Lista de espera.
- Capacidad máxima por clase.
- Notificaciones automáticas.

## Integraciones

- Google Calendar.
- Outlook Calendar.
- Mercado Pago.

## Branding y personalización

- Implementar acceso mediante subdominios (ver ADR-003).
- Personalizar logo, colores e información pública por organización.
- Permitir que cada organización configure su imagen institucional.
