# Turnos y Agendas

Aplicación SaaS para la gestión de turnos, reservas, clases y agendas de múltiples organizaciones.

## Objetivo

Permitir que gimnasios, estudios, consultorios, peluquerías y otros negocios administren sus servicios, horarios, profesionales y reservas desde una única plataforma.

## Tecnologías

### Frontend

- React

### Backend

- Django
- Django REST Framework

### Base de datos

- Supabase (PostgreSQL)

### Infraestructura

- Docker
- GitHub Actions
- Netlify (Frontend)
